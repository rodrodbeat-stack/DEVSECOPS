# DEVSECOPS TERMINATOR

Dashboard web de demostración con estética cibernética inspirada en interfaces sci-fi.

## Archivos
- `index.html`: estructura y vistas del dashboard.
- `styles.css`: diseño responsive, paneles, colores y animaciones.
- `app.js`: navegación, diagrama interactivo, simulador CI/CD, paneles y exportación de reporte.

## Ejecutar
Abre `index.html` en un navegador. No requiere instalación ni build.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube los tres archivos a la raíz del repositorio.
3. En Settings → Pages, selecciona Deploy from a branch.
4. Selecciona `main` y `/ (root)`, guarda y espera la publicación.

## Importante
Todos los indicadores y ejecuciones son de demostración. No se conecta a GitHub/GitLab, escáneres, Terraform, proveedores cloud ni Kubernetes, y no crea recursos reales. Para datos reales se requiere backend/API autenticada y configuración segura de credenciales.
